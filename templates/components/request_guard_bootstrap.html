{# Request-guard bootstrap (fork). Included in right after base_path_bootstrap.html. Wraps window.fetch once so every same-origin request from the classic UI carries "X-LM-Client: lm-classic". The backend rejects cross-site requests to state-changing GET routes unless they carry this header (py/utils/request_guard.py); modern browsers are let through by Sec-Fetch-Site anyway, the header covers browsers or proxies that do not send Sec-Fetch-Site. Cross-origin requests (Civitai, ...) are left alone so no CORS preflight is triggered there. #}
