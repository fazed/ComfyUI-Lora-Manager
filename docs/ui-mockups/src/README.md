# Mock-up D sources (design reference, not shipped)

`d-template.html` is the page; `extras.js`, `extras.css`, `detail.js`, `detail.css` are spliced in at the
`/*EXTRASJS*/`, `/*EXTRASCSS*/`, `/*DETAILJS*/`, `/*DETAILCSS*/` markers; `/*MOCKJS*/` and `__DATA__` are
the icon set and placeholder data. These files contain no personal library data.
